## 在线报告 / Read the report

### 四模型 NPC 探索实验 / Four-model NPC exploration experiment

**[查看中文报告 →](https://hoggqu.github.io/hog-tests/#zh)** · **[Read in English →](https://hoggqu.github.io/hog-tests/#en)**

让四种模型驱动同一个游戏 NPC，在相同初始条件下探索一张 384 格地图：

- Gemini 3.1 Flash Lite
- GPT-5.6 Luna
- DeepSeek Flash
- TypeSafe · Jev 1.13.0

报告涵盖实验环境、探索耗时、token 用量、行为合理性评分、网络延迟参考，以及按官方标价折算的费用。

Four models control the same game NPC, each starting from identical conditions on a 384-cell map. The report compares completion time, token usage, behavioral reasonableness, network latency, and estimated costs at official list prices.

> 每个模型展示一轮完整实验，结果不是通用模型能力排名。费用为带条件的估算，部分调用用量缺失，不代表最终账单。
>
> One complete run is shown per model. Results are not general model-capability rankings. Costs are conditional estimates, some call usage is missing, and the figures are not final bills.
